## 一页总结

调研把市场分为四类：题库刷题、记忆软件、家校通知和家庭协作记录。题库与家校产品降低了录入成本，
但通常不提供知识点级间隔排期；Anki、Quizlet、Brainscape、墨墨、RemNote 等记忆产品有更成熟的
排期，却假定学习者本人建卡并反馈。Push Kids 的差异化位置是：家长低成本录入真实已学内容，系统
确定性安排复习，家长保留确认权。

原文认为当前产品的主链路已经闭环，真正的底座缺口集中在两处：

1. 所有孩子和材料共用 `1/3/7/14/30/60` 固定阶梯，反馈只改变阶梯位置，不能表达材料与个体差异。
2. 知识点虽有稳定实体与出现历史，但名称仍是自由文本，别名归并、报表聚合和外部资源对接能力薄弱。

对复习机制最重要的竞品结论不是“换成 FSRS”，而是：

- 固定阶梯对平均难度材料可以是合理基线，不应被描述成错误算法。
- 自适应算法的价值来自不同材料、不同反馈后产生分叉，而不是某一组神奇间隔。
- 家长代评的语义噪声高于学习者自评；先把“独立完成、提示后完成、没有想起、未练”区分清楚，
  比先引入复杂模型更重要。
- 排期应成为版本化策略层，支持孩子默认节奏、科目覆盖和积压收敛，同时保持日期计算确定、可审计。
- 真实课堂证据并不支持对学习效果作强承诺；产品应承诺“帮助记录和安排”，不承诺掌握率或提分幅度。

## 竞品对 Push Kids 的可迁移启发

| 竞品类型 | 可借鉴 | 不应照搬 |
|---|---|---|
| 记忆软件 | 分级反馈、策略参数、失败后重建、维护复习 | FSRS 默认参数、成人卡片评分话术、预测掌握率 |
| 题库刷题 | 低摩擦录入、同类内容回看 | 自动批改、题库扩张、把答题量当进度 |
| 家校通知 | 缺项/到期/近期变化的低频摘要 | 教师布置权、强制触达、用通知替代站内事实 |
| 家庭协作 | 家长确认、家庭共享、可追溯记录 | 积分排行、公开比较、儿童社交发布 |

## 已转化为设计决策的内容

- 保留固定阶梯作为旧策略和冷启动基线，不原地替换历史结果。
- 新增确定性 Review Policy V2，而不是接入模型判断或直接移植 FSRS。
- V2 使用明确的观察结果驱动：独立完成、提示后完成、没有想起、今天未练。
- 新内容默认走“均衡”节奏；可按孩子设置，并允许科目级覆盖。
- 逾期只形成一个待检查状态，不补造错过的多轮 Todo；实际完成日是下一轮的时间锚点。
- 长期内容进入维护阶段，不把完成某轮写成“已掌握”；停止自动复习必须由家长明确操作。
- 旧客户端、旧 Review 和新策略通过版本字段渐进共存；迁移不得突然改写现有到期日。

详细算法、状态机、迁移和验收标准见关联 Spec。

## 原文中的其他产品判断

- 优先级：排期策略参数化、知识点身份层、提醒闭环。
- 明确不建议：积分排行式激励、自建题库/讲解/出题、未经授权复制或采购全量知识点树。
- 体验目标：围绕家长晚间几分钟完成确认与反馈，降低解释和操作成本。
- 发布风险：儿童个人信息、删除与导出能力、微信类目和订阅消息可达性必须作为上线门禁。

## 证据限制

- 调研是限定范围内的竞品扫描，不足以证明市场上绝对不存在同定位产品。
- 多数自适应排期证据来自成人、语言或卡片材料，不能直接外推到小学全学科。
- 厂商公布的预测精度、复习量节省和效果数据不能等同于独立课堂效果。
- 家长反馈是否足以驱动自适应排期，仍需用真实使用数据验证；在证据形成前必须保留回退到固定策略的能力。
