# 小程序前端发布

## 1. 发布目标和状态

前端发布分为四个互不等价的状态：

| 状态 | 可使用人群 | 到达方式 |
|---|---|---|
| 开发预览 | 开发者 | 微信开发者工具预览 |
| 开发版本已上传 | 管理员可在后台看到 | 开发者工具或 CLI 上传 |
| 体验版 | 已配置的体验成员 | 后台“选为体验版” |
| 正式版 | 微信用户 | 提审通过后后台“发布” |

不得把“CLI upload 成功”报告为“全网已发布”。

## 2. 发布前自动检查

在仓库根目录执行：

```bash
npm install
npm test
npm run lint:miniapp
npm run check:miniapp
```

同时人工或代码审查确认：

- `apps/miniprogram/config.js` 的 `useCloud=true`。
- `cloudEnv=prod-d2g14rwoycac6b45d`、`cloudService=flask-ik19`。
- `apps/miniprogram/project.config.json` 使用真实 AppID，且 `urlCheck=true`。
- 小程序包中没有 `.env`、密钥、数据库地址、OpenID、儿童图片或测试数据。
- 后端目标版本已经灰度稳定，`/health/live` 和 `/health/ready` 均为 200。
- 两个真实微信账号已完成家庭隔离、图片 owner 和主业务流程 smoke。

任一项失败都停止上传。

## 3. 预览与上传

macOS 默认 CLI：

```bash
WECHAT_DEVTOOLS_CLI=/Applications/wechatwebdevtools.app/Contents/MacOS/cli
MINIPROGRAM_PATH=/Users/bytedance/Documents/push_kids/apps/miniprogram

"$WECHAT_DEVTOOLS_CLI" islogin --project "$MINIPROGRAM_PATH" --lang zh
"$WECHAT_DEVTOOLS_CLI" preview --project "$MINIPROGRAM_PATH" --qr-format terminal --lang zh
```

登录状态、预览编译和包体均正常后，使用本次批准的版本号上传：

```bash
RELEASE_VERSION=0.1.1
RELEASE_DESCRIPTION='修复说明或功能摘要'

"$WECHAT_DEVTOOLS_CLI" upload \
  --project "$MINIPROGRAM_PATH" \
  --version "$RELEASE_VERSION" \
  --desc "$RELEASE_DESCRIPTION" \
  --lang zh
```

要求：

- 版本号不可复用；下一次发布递增 patch，例如 `0.1.0` → `0.1.1`。
- 说明必须描述用户可见变化或修复，不得写成“测试”“随便改改”。
- 上传报告记录版本、说明、包体、AppID、配置环境和检查结果。
- CLI 登录需要开发者本人扫码时，按本目录的“需要人工操作”格式输出。

## 4. 体验版人工门禁

```text
【需要人工操作】设置体验版并添加体验成员
原因：微信公众平台的账号权限、成员授权和扫码必须由管理员完成。
操作入口：https://mp.weixin.qq.com/
导航路径：管理 → 版本管理 → 开发版本 → 目标版本 → 选为体验版；成员管理 → 体验成员
需要填写/选择：选择刚上传且版本号、说明、上传时间均匹配的版本；添加 iOS、Android 和第二家庭账号。
完成标志：目标版本显示“体验版”，体验成员可扫描体验版二维码进入。
完成后回复：已完成体验版配置
```

体验版至少验证：

1. 新微信账号可创建家庭或进入明确的加入流程，不依赖人工录入 raw OpenID。
2. 第二账号申请加入、管理者批准、角色权限与退出/撤销符合预期。
3. 文字、1 张图片、9 张图片、失败图片、断网重试和取消流程正常。
4. AI 输出明确是可编辑建议；家长确认前不产生正式记录和 Todo。
5. 历史记录、今日、日历、报表和设置可用。
6. 两个家庭互相不可读写；非 owner 不可读取图片。
7. iOS、Android 均验证相册、相机、隐私授权和后台恢复。

## 5. 备案、认证、类目和隐私人工门禁

```text
【需要人工操作】完成正式发布资质与隐私配置
原因：备案、认证、服务类目和隐私声明是主体对外陈述，必须由账号管理员确认。
操作入口：https://mp.weixin.qq.com/
导航路径：首页发布准备；设置 → 基本设置；设置 → 服务内容声明 → 用户隐私保护指引
需要填写/选择：
- 小程序备案必须显示已完成；微信认证完成后才具备完整搜索和分享能力。
- 服务类目必须与“家长使用的家庭学习记录与复习管理工具”真实一致，并提交平台要求的资质。
- 如实声明选中的照片或视频、摄像头、微信身份、家庭关系和儿童学习内容的用途。
- 写明私有存储、最短必要保留、删除/投诉渠道，以及火山引擎方舟 Ark 等第三方处理方。
完成标志：备案完成；目标类目有效；隐私保护指引审核通过；相关隐私接口在体验版可用。
完成后回复：已完成发布资质与隐私配置
```

不得为绕过审核选择不相关类目，不得遗漏儿童照片、微信身份或第三方 AI 处理事实。

## 6. 提交审核人工门禁

```text
【需要人工操作】提交微信审核
原因：提交审核会向微信作出正式功能、类目和隐私陈述，必须由管理员最终确认。
操作入口：https://mp.weixin.qq.com/
导航路径：管理 → 版本管理 → 开发版本 → 目标版本 → 提交审核
需要填写/选择：版本说明、功能介绍、审核操作路径、真实服务类目、隐私信息和必要资质。
完成标志：目标版本进入“审核中”，后台显示提交时间和审核单状态。
完成后回复：已提交微信审核
```

推荐审核说明：

> 知芽是供家长使用的家庭学习记录工具。家长可以手动输入或上传学习材料照片，系统只生成
> 可编辑建议；只有家长确认后才形成正式学习记录和复习事项。AI 不自动评分、不判断掌握程度、
> 不进行孩子间排名，也不预测下一步课程。审核人员可首次进入后创建独立测试家庭。

推荐审核路径：

> 首次进入创建家庭 → “记录”页提交文字或照片 → 查看并编辑分析建议 → 家长确认 → “今日”页
> 查看复习事项 → “报表”页查看记录；“设置”页可管理孩子、科目、活动和家庭成员。

如果审核人员无法自行创建隔离的测试家庭，必须先修复审核可达性，不能提交一个只能靠后台手工
绑定审核员 OpenID 才能使用的版本。

## 7. 正式发布人工门禁

```text
【需要人工操作】发布微信正式版
原因：审核通过不等于上线；最终发布会让普通微信用户访问，必须由管理员确认发布范围。
操作入口：https://mp.weixin.qq.com/
导航路径：管理 → 版本管理 → 审核版本 → 发布
需要填写/选择：优先选择平台支持的灰度/分阶段范围；确认版本号与已验收版本完全一致。
完成标志：版本出现在“线上版本”，普通非开发/体验账号能够扫码打开。
完成后回复：已发布微信正式版
```

发布后立即用普通微信账号验证搜索/扫码、首次进入、隐私弹窗、图片上传、家庭隔离和主流程；
出现跨家庭访问、公开图片、重复正式写入或隐私接口不可用时立即停止放量或回退前端版本。
