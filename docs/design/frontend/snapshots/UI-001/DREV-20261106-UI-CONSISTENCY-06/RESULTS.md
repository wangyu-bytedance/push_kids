## 发现与修正

- 首轮部分大插画经CSS变量未显示；改用嵌入的img元素并等待图像解码，保持原始图片不变。
- 旧底稿中的固定绿色文字不适合深色主题；字段标签、文字操作和说明改为主题语义颜色。
- 危险按钮的禁用色被高优先级样式覆盖；已修正，确认条件不满足时呈现禁用态。
- 活动行图标的旧颜色选择器仍优先生效；提高本轮主题规则的明确作用范围并重新导出全部组合。
- 错误页增加明确“重新加载”入口。键盘焦点由交互检查保留，静态效果图导出使用未聚焦状态。
- 旧底稿清理家庭和清理孩子共用示例不够明确；补为第65个独立家庭确认场景，不改变真实删除逻辑。

根目录probe.json/probe-board.png仅为开发阶段检查，不列入本次988项当前PNG证据。
