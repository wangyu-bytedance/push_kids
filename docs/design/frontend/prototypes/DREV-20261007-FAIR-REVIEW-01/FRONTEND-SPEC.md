## 交互与信息

今日主句只显示安排项数/分钟；根据用户2026-10-07截图反馈，删除排期规则说明与等待总数两段文字及其分隔线。
完成态只显示今天安排的内容已完成，不追加规则说明或未入选数量；后台保持当天清单稳定、不自动追加。
小预算/家长预约耗尽预算时显示“本次预算未能覆盖所有待复习科目”，不指责家长/孩子。
旧版本仅说明清单稳定，不宣传尚未启用的新公平策略。

条目保留科目/名称、次数、上次复习、调整按钮。自动日期明确标注“建议复习日”，另起一行说明实际安排。
预约只显示“家长安排日期”；不推导被覆盖的自动建议日期。未来预览继续说明并非保证。
等待状态用中性色，不用逾期红色；日期以服务端上海日期为准。
“等待安排”附一句共享说明：“到了建议复习日后，还需按当天预算安排。” 不在每条重复长解释。

## required viewport/state matrix

所有以下状态分别导出320×568、390×844、430×932，DPR=1，共39张PNG；页面可纵向滚动。
这些是设计增量裁片，不是完整原生页面截图，不为既有导航或反馈组件创造新设计。

| URL state | 设计状态 | 核验 |
|---|---|---|
| today | 今日有计划和等待项 | 只显示安排项数/时长与三科示例，非真实排期预测 |
| completed | 今日已完成仍有等待项 | 仅声明今日计划完成，不显示等待总数 |
| limited | 无法覆盖所有科目 | 中性说明，不暗示必须加时 |
| clear | 今日有计划且无等待项 | 与有等待项时同样简洁，不展示等待总数 |
| waiting | 到了建议日但未入选 | 日期与等待状态分开 |
| scheduled | 已入今日计划 | 明确已安排，次数仍可为0 |
| reviewed | 今日已复习 | 显示今日状态及下次建议日 |
| deferred | 家长今天跳过 | 不误算系统落选/复习 |
| future | 尚未到建议日 | 不显示等待/逾期 |
| reserved | 家长未来预约 | 家长日期与自动日期语义分离 |
| ungenerated | 尚未生成今日计划 | 只读页不隐式生成 |
| legacy | 后端缺少新字段 | 计划日期，安排状态待更新；不猜测 |
| long | 长中文与只读态 | 自动换行、无调整按钮 |

loading/error/retry/空列表、权限失败及调整弹层沿用现有批准设计；本次不改变外观，实施后仍跑回归。
所有新业务状态来自服务端；按钮/筛选遵循现有流程，原型“调整”只展示现有占位交互且不执行数据写入。

## 工程要求与验收

正文≥14px，按钮≥44px；单列、无横向拖动；禁用时明确原因，文本不依赖颜色。
没有新增表单、图表、媒体、动效或运行时依赖。UI不计算等待分数/优先级，不存儿童内容到localStorage。
请求错误保留既有列表和重试方式，切孩子/退出丢弃旧响应；viewer只读。
使用现有tokens/atoms；原型内颜色为批准token的静态副本，生产不得另起token体系。
实现验收必须另留原生三视口节点几何、DevTools编译、iOS/Android阅读及反馈测试，设计PNG不能替代。
