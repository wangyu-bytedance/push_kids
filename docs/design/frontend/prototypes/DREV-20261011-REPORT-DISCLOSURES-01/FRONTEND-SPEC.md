## 方向与位置

报表是阅读和下钻页面。沿用暖白纸面、松绿标题、低对比边界和既有字阶，用两张同尺寸折叠卡收纳详情；不要增加新的大标题或在顶部抢占图表空间。两块严格置于「科目学习记录」之后、「课外活动投入」之前，顺序是历史记录、编辑计划。两张卡各自有≥44px整行点击区、文字名称、计数（仅真实可得时）和上下箭头；两个区可独立展开，默认都收起。两张用户截图作为现有控件外观参考；第二张截图中的旧名称由用户2026-10-11更正为「编辑计划」。

## 展开内容与边界

- 历史记录展开后保留已确认/待处理/全部、搜索、筛选、有界分页、待处理状态和详情入口。折叠标题可显示服务端待处理数；请求失败时不伪造计数。
- 编辑计划展开后保留现有复习条目的时间/科目/次数选择、按原规则组织的有界条目、日期/状态和当前权限允许的就近操作。独立页面的可见标题也改为「编辑计划」，同一控制器只维护一份行为。
- 在任何区收起时，下面板块自然上移；同时展开时按页面纵向滚动，不叠盖下方活动内容。切孩子、离页和迟到响应不得泄露上个孩子的行。
- 截图 `review-open`、`both-open` 只拍到展开列表的首屏上半段；自然滚动继续显示其余条目和活动板块。设计源不以隐藏溢出代替完整内容。
- 记录页留新增表单与待处理提醒。Today/科目历史意图进入报表对应区；手动新增仍进入记录页。
