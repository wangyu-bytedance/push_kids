## 本轮用户反馈与视觉选择

用户：“现在的设计非常的整齐了，但是我想更佳美观和好看，现在设计有点老气”。
本轮保留上一版信息分组与操作顺序，改变字体、色温、层次、图形和按钮形状。

方向：**现代、清透、轻盈的家庭陪伴应用**。无衬线标题、明亮中性色、鲜活绿、
少量蓝/杏/浅绿语义色块、柔和几何图形与轻质白卡；没有常驻装饰动画。

| 维度 | DREV01 | DREV02 候选 |
|---|---|---|
| 字体 | 宋体标题，纸质手账感 | 系统中文无衬线，标题 29px/700，窄屏 25px；正文 16px，说明 14px |
| 色温 | 米黄暖纸 | 清透浅底 #F5F8F7，纯白 #FFFFFF 内容面 |
| 操作主色 | 松绿 #1F5B45 | 鲜活绿 #147D66；按明确操作层级使用 |
| 卡片 | 暖白、发丝描边 | 20px 圆角白卡、极轻阴影；内容之间靠留白和细分隔线 |
| 按钮 | 胶囊形较多 | 12px 圆角矩形；添加入口统一浅绿实底，48px 高 |
| 科目 | 文字按钮 | 图标 + 名称；语文杏色、数学浅蓝、英语浅绿，保持标签语义 |
| 图形 | 基础线性功能图标 | 功能图标继续统一；照片入口增加同一风格的轻巧几何相机/相册图形 |
| 导航 | 同一选中态 | 保留五 Tab 与统一选中态；降低未选中图标的存在感，文字仍清楚 |

这是**待批准的视觉基线变化**：不再宣称继承现有 FDB 的暖纸/衬线外观。
现有 `FDB-20260913-04` 和 `FEC-20261007-NATIVE-GEOMETRY-02` 继续是生产权威；
本稿不覆盖生产基线，不修改任何小程序样式或已批准快照。生产实施前必须批准具体基线、Spec 与 DREV。

## 控件、状态与图表合同

- 全部产品按钮、输入、文本域触控宽高≥44 CSS px。320 周历使用全宽点击区域。
- 添加入口保持同一浅绿底、图标、字重、圆角和高度；不重现原截图中的系统默认灰底。
- 卡片/表单布局沿用 DREV01；长页滚动，保存与底部导航保留独立空间。
- 代表性交互仍有：导航、折叠、时长输入联动、退出保留输入、字段错误定位、昵称确认清理状态。
- 日期/照片/成员等是固定合成示例。保存、审批和删除均无真实副作用，未申请照片或麦克风权限。
- 手动记录与 AI 草稿都由家长确认；不评分、不宣称掌握，不修改确定性复习规则。
- 单 active family、六位申请核验码、19:00 提醒摘要保持；通知偏好与授权、服务可用性分别表达。
- 报表数值、日期、范围、单位及方格/列表内容保持 DREV01，仅应用本轮视觉色板。未新增图表编码。
- 深色正文 #1D302B，关键次要文字 #5D7166。主按钮白字/绿底对比度约 5.05:1；
  关键次要字/浅底约 4.89:1。科目名称使用较深字色，保留柔和底色，不靠降低可读性制造轻盈感。
- 几何图形都是本地 SVG，风景仍为合成占位图；没有真实儿童照片或身份资料。
