## 视觉与范围

沿用 PKDS-2.0 暖纸松绿，修正“编辑计划”列表页脚与操作结果提示的几何。
页脚指截图中“回到首页 / 第1页 / 下一页”的列表分页及其与“收起编辑计划”的间距；
底部五个 Tab 作为上下文显示，不批准修改其样式或导航。
同时覆盖报表内嵌组件和独立编辑计划页；原有筛选、条目数据和删除/改期流程不变。

## 可见合同

1. 分页使用不换行 Flex：左右按钮等宽，中间页码64px，页码两侧各8px。
   按钮最小44px高、14px文字、现有token圆角，浅绿底和细描边，无阴影。
   实施时复用`--pk-r-md`，不新增圆角值。
2. 首页“回到首页”禁用；末页“下一页”禁用；加载中两个按钮禁用。
   禁用使用透明底、弱文字与轻描边，保持布局和点击热区，无系统默认白块。
3. 长页码只在中央64px内换行，按钮不掉到下一排；文字放大时允许按钮纵向增高。
4. 分页上下16px，与现有最小44px“收起编辑计划”区域连贯，移除截图中分页换行造成的多余空白。
5. 操作结果由独立的`view.inventory-feedback`包裹`text.inventory-feedback-text`。
   容器水平16px、垂直12px内边距，最小44px高；文本14px、1.5行高、左对齐，
   单行垂直居中，长文自然换行。暖色底、现有提示描边和松绿文字保留。
6. 两处原`.notice`（操作结果、预算提示）一起迁移到专用结构，避免再次与全局通用类发生冲突。
   只读文本保留原结构；操作结果继续`aria-live="polite"`。删除成功完整文案不改。
7. 科目目录分页同样采用两个等宽Flex按钮，间距8px；不新增页码或改变科目加载规则。
