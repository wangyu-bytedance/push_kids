## 方向与边界

操作与回忆浏览结合：沿用暖白纸面、松绿强调、宋体标题、系统中文正文、4px间距和44px触控。
从照片记忆出发，信息来源、未知值和待确认状态保持清楚；人工录入与AI路径同级。
桌面显示评审工作台与可切换尺寸的手机，手机直接显示全屏交互。

所有孩子、照片、日期、地点为合成示例。照片使用内嵌SVG插画，不能视作AI识别效果。
地图是按坐标布局的点位示意，持续标注“位置示意 · 非真实底图”；没有真实底图、边界、道路、GPS或检索。
全球能力是首版需求，候选自适应聚焦主要区域并提示其他区域；技术可用性仍须独立验证。

## 已确认与后续技术门禁

用户已确认：事后出游回忆；家长确认后入正式足迹；足迹相册而非原画备份；首版支持全球并随主要轨迹自适应。
第二轮已确认：当前筛选范围的主要区域聚焦并提示其他区域+看全部、空态中国、地点点亮+城市/国家汇总、每批一个孩子、无日期留草稿/有日期无地点可入时间线、从记录页进入并按日期整理。
第三轮已确认：未确认草稿7天自动清理；首次开启后仅缺地点按需AI、可关闭；地点＋当地日期为到访日；回放镜头跟随；几十张照片分批整理、离开可继续。用户在Q10选择7天，未接受长期保留推荐。
第四轮已确认：每张上传成功起固定7天、编辑/重试不延长，显示清理日期，只清未确认项；元数据/派生图成功后解析原件24h清理，失败原件至第7天；足迹内可访问归档孩子旧草稿而不能新增；逐张正式照片纠正/删除后同步统计。
产品分支与整体共同理解已由Q19确认，本DREV获设计范围批准；实际服务、工程阈值、Task Spec/架构的生产实施批准尚未取得。

## 关键交互

1. 记录页入口 → 足迹时间线。当前孩子切换后显示该孩子内容，时间筛选在三个视图间保持。
2. 导入 → 示例选图 → 首次信息处理说明。AI由家长明确开启；后续批次沿用当前成员偏好，仅缺地点时演示候选，设置内可关闭；拒绝后可手动记录。
3. 解析 → 逐张草稿。每张显示日期/时刻精度、地点、信息来源、未知与AI候选；可修改、全选、批量改时间/地点。
4. 确认 → 展示所选数量、已定位/未定位和剩余草稿 → 家长确认真实到访 → 保存结果。
5. 时间线按拍摄日期排序，点击照片看详情；地点未知仍可浏览，未知日期先保留草稿。
6. 回放支持播放/暂停、进度拖动、下一地点；显示当地日期时间并以当前地点为镜头中心。虚线仅为时间顺序，不暗示真实道路和速度。
7. 点亮支持自适应/中国/世界，地点点开看“来过几天”、每个当地日期和照片；同日多张合一个到访日，未定位照片有独立入口。
8. 解析失败保留其他结果，地图失败回退时间线；只读状态隐藏写入口。
9. 草稿逐张显示固定清理日期；选中项确认后移出草稿，余项保留原期限；下一批追加而不覆盖，当前本机可刷新继续虚构演示。
10. 孩子选择器 → 查看已归档孩子 → 历史/旧草稿；可在期限内确认或删除草稿，不可新增。
11. 正式照片详情 → 修改日期/地点，或删除确认 → 三视图与地点/城市/国家统计重算；同地其他照片保留。未知/未匹配地点不编造坐标。

以下27态均要求320×568、390×844、430×932，DPR=1 PNG；总计81张手机图，另附1张桌面评审工作台。

| empty | 首次空态，照片和手动两个路径 |
| import | 多选示例照片、导入、手动入口 |
| consent | 信息处理说明与可选AI |
| importing | 单图进度、查看成功结果、取消 |
| review | 来源、逐张选择和修改、未知值 |
| batch | 批量时间/地点表单 |
| confirm | 所选去向汇总、家长确认 |
| saved | 入档成功与剩余草稿 |
| playback | 时间回放入口、播放器与示意连线 |
| paused | 播放器处于中间地点的暂停状态 |
| lit | 主要区域、地点点位、其他区域提示、未定位提示 |
| world | 全球点位总览 |
| place | 同地到访日、照片数与按日期分组抽屉 |

## 图形编码选择

时间线以日期和照片卡片承担回忆浏览；等宽瀑布卡片会打乱时间阅读，故不采用交错列布局。
空间用地点点位/聚合表达真实离散到访，回放以虚线明确顺序；不画真实道路或以速度为动画含义。
整省/整国填色容易把单点到访扩大为覆盖范围，第二轮已排除首版，不加入本候选。
全球相近点需聚合或列表展开，不能让相互覆盖的标记成为唯一访问入口。

## 验证与限制

导出脚本检查JS错误、水平边界、按钮/文本输入44px，并通过真实点击走通示例主流程。
对话框支持Esc和Tab焦点循环；系统字体、焦点轮廓、信息来源文字和减少动画偏好纳入设计。
DOM检查不能替代截图视觉审阅，也不证明原生节点几何、系统相册授权、地图覆盖层、读屏、字体放大或iOS/Android可用。
未接后端、数据库、照片解析、Ark、地图服务、真实家庭身份或存储。本轮不做生产发布。
虚构相册、草稿和AI偏好在本机localStorage中演示续接，可随时重置；确认/编辑/删除会更新同一份示例数据并重算三视图。新地点只有匹配内置虚构地点才能演示坐标，否则留在时间线；没有真实地理检索。
7天边界用固定演示时钟验证资格与清理后的UI，不证明后端任务、对象删除或并发正确；未实现真实照片保存、跨设备恢复与服务端媒体清理。本机演示不能成为生产客户端存储儿童照片/GPS的依据。
