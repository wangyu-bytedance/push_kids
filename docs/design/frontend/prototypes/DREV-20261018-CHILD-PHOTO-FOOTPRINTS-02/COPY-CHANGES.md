# 足迹文案精简 — 生产实施清单（待批准）

关联：SPEC-20261018-FOOTPRINTS-UI-COPY-01 / DREV-20261018-CHILD-PHOTO-FOOTPRINTS-02。
当前仅有隔离设计候选，以下是批准后的生产改动目标，不表示已经修改小程序。

| 位置 | 当前 | 目标 |
|---|---|---|
| 首页 | 走过的地方，都有回响 | 删除装饰性副标题，保留孩子足迹标题 |
| 归档/只读 | 可浏览历史、继续核对旧草稿；不能新增照片 / 当前家庭角色只可浏览足迹 | 已归档 · 可整理旧草稿 / 只读 |
| 待核对入口 | N条回忆待核对 · 7天内确认 | N张待核对 |
| 缺地点提示 | 有N张照片待补地点，仍可在时间线浏览 | N张待补地点 |
| 空态 | 第一枚足迹，从一张照片开始 + 把过去走过的地方，慢慢收进相册 | 还没有足迹 + 导入照片 / 手动记录 |
| 时间线操作 | 查看到访与全部照片 / 继续查看更早的回忆 | 查看照片 / 查看更多 |
| 全球图 | 从下方选择地点或区域，打开详细地图 | 删除操作教学；保留地点列表和位置示意标签 |
| 地图转换 | GPS待地图转换，可先从时间线补选位置 | N个到访日暂未显示在地图上；不把已确认数据谎称为待确认 |
| 回放 | 按当地日期和到访顺序播放，虚线只示意顺序 | 连线为顺序示意 |
| 导入标题 | 整理前，先了解一下 | 导入照片 |
| 导入说明 | 元数据提取、展示图生成等实现步骤 | 仅保存浏览版照片，不提供原图备份；上传7天后未确认照片自动清理 |
| AI同意 | 开启AI地点候选 + 多句触发规则 | AI辅助补地点（可选）；仅将缺地点的照片交由火山方舟识别，可在设置中关闭 |
| 足迹设置 | 各处重复存储规则 | 在现有设置集中保留固定7天、不延期、成功后24h清原件、正式照片保留等完整规则 |
| 核对标题 | 核对这些回忆 / 核对后才是孩子的足迹 | 核对照片 |
| 核对来源 | 每张重复显示照片元数据 / 照片GPS等 | 核对列表仅保留AI候选标记，来源在详情或编辑页简述为“照片信息”或“家长填写” |
| 草稿到期 | 清理时间 + 修改不会延期等重复解释 | 每张显示具体日期“到期”；固定期限细则在设置 |
| 核对空态 | 暂时没有待核对照片；到期未确认的草稿会自动清理 | 没有待核对照片 |
| 确认 | AI与照片元数据都是线索、确认后才成为正式足迹等重复解释 | 照片数量、待补地点数量、简短家长实际到访确认、确认入档 |
| 批量编辑 | 仅修改已选择的条目；留空保持原值 | 留空项不修改 |
| 日期/时间 | 日期不可信，改为未知 / 时刻不可信，改为未知 / 不补造时间 | 清除日期 / 清除时间 / 未填写 |
| 同日顺序 | 数字较小的先播放，默认0 + 不改变拍摄时刻 | 同日播放顺序 |
| 编辑页 | 未知日期留草稿、上传时间不会替代拍摄时间等规则解释 | 删除说明，保留必填与错误反馈 |
| 删除确认 | 三种视图、到访日重算等实现规则 | 删除后无法恢复，其他照片保留 |
| 放弃编辑 | 已上传草稿仍保留，未保存的填写内容将丢失 | 未保存的修改将丢失 |
| 地点/照片详情 | 同地同日统计规则、点开查看等说明 | 来过N天、日期、照片及来源；删除操作教学 |
| 成功反馈 | 三种视图和统计已更新等 | 已保存 / 已入档 / 已删除 |

不删除：授权范围、AI可选与候选属性、实际到访确认、具体到期日期、删除/放弃后果、缺失/失败状态、重试与手动路径、地图及连线示意标签、必要输入错误。没有新增数据、权限、AI调用或后端规则；文案简化不改变固定期限和未知值行为。

本HTML沿用DREV01的结构作为文案预览；实际原生控件（清空字段、同日顺序等）的文案目标由本表列出，原有视觉差异仍按Spec04单独验收。
