## 页面和状态

Operate：暖白纸面、松绿选中态、衬线标题、系统正文；单列条目，以真实复习次数和日期支持家长决策。
沿用既有设计token和五Tab；报表入口进入二级原生导航页，返回保留报表日期范围和孩子。
源码参数 `?state=` 支持以下状态；可点击三种查看方式、日期、科目、调整、取消和删除。

| state | 合同 |
|---|---|
| entry | 报表标题下、区间统计前的“复习条目”入口；统计区块只占位表示原有内容继续，不批准重设计统计 |
| today | 删除下一次复习后的今日空态；原有学习/活动内容在生产实现中保留 |
| time | 明天/后天两日期，计划项数、分钟、动态预览说明；默认明天 |
| after | 后天选中；独立展示后天的条目，验证切换日期 |
| subject | 不含“全部”，默认首个科目；与日期相同的标题/副文案/下划线样式，每行最多三个，含零条科目 |
| count | 直接点选全部/0次/1次/2次/3次/指定次数；三列换行下划线风格，无下拉框或重复标签 |
| count-exact | 精确1次，列表只显示已复习1次的条目 |
| count-custom | 指定次数打开数字输入弹层；确定才应用，关闭/取消保留旧结果；支持0..2147483647整数 |
| count-empty | 具体次数没有结果，显示匹配次数并可清除筛选 |
| actions | 删除条目使用danger红色文字，说明保持次要色；展示动作及后果；加入明天，或仅明天条目改到后天；次数不变 |
| delete | 明确物理删除知识/复习历史/后续安排；其他同批材料保留，二次确认 |
| empty | 时间无安排；可切换次数视图，无虚构条目 |
| error | 页内错误+重试，不将异常显示成0条 |
| readonly | 可浏览，无写操作按钮 |
| long | 长知识名称完整折行，不缩小关键文字或隐藏横溢出 |
| pending | 保存中，禁止重复动作；实际离开页面不能声称取消已发服务端事务 |
| conflict | 安排被另一端修改，读取最新后重新操作，不覆盖新值 |
| budget | 手动安排超过日常分钟预算的解释；硬上限满额时409留在操作页 |

## 数据、操作和恢复

- 日期和次数全部由服务端给定，前端不执行排期策略。复习次数不是轮次，不是学习出现次数。
- 科目/次数视图不受近7/30/100天过滤；按科目仅选单科，无全部入口，零条科目仍可选。
- 次数筛选是精确等于N次，不是N次以上；全部次数仅存在于按次数视图。常用0..3直接点击立即应用，其他次数通过弹层指定输入。
- 弹层未确定或取消不改变已应用条件；非法值保留弹层输入与旧结果。确定0..3选中对应快捷项；其他次数将“指定次数”显示为当前“N次”并选中，再点可修改。
- 结果标题只有条目数，不放右侧假交互的排序文字。全部次数时下方仅保留一句固定排序说明；具体次数时显示“已复习N次”，隐藏排序说明。科目视图也移除重复排序文案。
- 服务端SQL执行次数等值过滤、总数与分页；不能只筛当前已下载的一页。次数变化重置游标并丢弃旧响应。
- 列表最多50行在页面状态中，用户下一页替换当前页；科目目录同样有界分页，不无限加载。
- 生命周期：initial/loading/content/empty/error/readonly/not-found/pending/success/conflict。
  首屏用现有骨架；分页错误保留已有页；权限失效停止动作；已删除关闭弹层并刷新；归档明确只读原因。
- 请求generation绑定family/child/filter/day；旧响应丢弃。写入成功失效游标后重查，不能在排序已变化时继续append。
- 改期失败保留条目与选项、显示错误；不做假成功乐观状态。删除取消零写入。
- “加入明天”若已安排明天不可重复；“改到后天”若非明天则禁用并说明；已结束可加入明天重启轮次。
- 精确来源复用已批准SOURCE-DELETE-02合同，原图无新增设计变化；禁止全量下载儿童照片作预览。
- 原型全部数据只是可交互示例；不调用真实API，不代表功能已经实现。
