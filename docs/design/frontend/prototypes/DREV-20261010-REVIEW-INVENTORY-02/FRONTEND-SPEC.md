## 设计方向

保留纸芽的暖白纸面、松绿强调、衬线摘要和柔和分组边界，用一层筛选和一张可扫读的知识清单代替重复标题、冗长说明与逐条大卡片。页面属于操作型界面：先选范围，再看条目，最后在条目右侧“…”调整。

## 页面结构和交互

原生导航栏已显示“复习条目”，内容区不再重复页面标题或“看看学过什么”文案。导航下直接放按时间/按科目/按次数三种查看方式；下方始终只有一层与当前查看方式匹配的筛选。

- 按时间：明天/后天使用一个两段选择器；摘要只写“预计 N 项 · 约 N 分钟”和随今日反馈更新的短说明。结果按当前页科目折叠，默认第一组展开，其他组收起。
- 按科目：一个“科目 · 英语 16项”选择入口；选择列表中继续支持服务端科目分页。已选科目内直接使用有分隔线的清单，不再重复显示一张只有同一科目的折叠卡。
- 按次数：一个“次数 · 已复习1次”选择入口；弹出的选择器包含全部、0/1/2/3及“指定次数”，只有确认自定义数字后才显示该数字。结果按当前页科目分组并可折叠。
- 条目：每项只占清单的一行区域，完整标题可换行；随后显示已复习次数、最近复习、建议/家长安排日期和当前安排状态。右侧固定44×44操作目标打开就近下拉菜单，菜单保留现有加入明天、改到后天、删除及各自禁用条件。删除仍有二次确认。
- 状态：未来预计入选与今日已安排是两个不同事实；效果图分别放在摘要和条目状态，不把未来预览显示成已经锁定的日计划。只读模式不显示“…”；空结果显示单一空态；加载、错误、冲突、保存中继续遵循现有反馈规则。

## 相比现有截图解决的问题

1. 顶部不再有原生标题和内容大标题的重复，也不再连续显示两段解释。
2. 科目和次数不再把多个筛选按钮铺成两行；当前选项有明确的单一入口，结果获得更多首屏高度。
3. 同科条目使用一张纸面清单和细分隔线，避免每项一张大卡占满屏幕；按科目视图也不会再次重复科目标签。
4. 日期、次数和状态按相同顺序对齐；“…”固定位置和大小，菜单在320px窄屏也完整落在视口内。

## 实现边界

仅在用户批准本 Spec revision 与 Design Revision 后改小程序。复用现有有界目录API、科目游标、排期/删除权限和服务端策略；不下载全量知识、不计算排期优先级、不改次数或反馈事实。生产几何沿用FEC的320/390/430原生矩形门禁，长标题、44px触控和菜单不越界必须实测。
