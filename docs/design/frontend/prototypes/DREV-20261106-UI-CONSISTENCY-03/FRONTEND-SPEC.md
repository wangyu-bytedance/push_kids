- Surface: Operate。比较同一设置页的六种视觉语言，方便家长选择风格。

## 设计范围

本轮只有设置页，六版均使用相同合成数据与内容顺序：孩子小禾、三个科目、两项课外活动、两项每日任务、出行安排与四个管理入口。页面可滚动，底部五个 Tab 顺序不变。390×844 首屏均完整显示两类添加按钮；320×568 通过滚动继续查看。

原先 DREV01/02 的 17 路由、39 场景仍为历史候选；本轮不是全应用的六套成稿，也没有证明其他页面采用新视觉后的布局。风格选择后再扩展对应界面与交互状态。

## 六个独立方向

| 选项 | 视觉方向 | 字形、材质与结构 | 取舍 |
|---|---|---|---|
| A 极简画廊 | 近白、炭黑、灰绿 | 大字无衬线标题、细线分组、无外卡片、圆形线框图标、描边添加按钮 | 清晰克制，趣味最少 |
| B 晴空蓝白 | 钴蓝、蓝白 | 连续蓝色页头、白色圆角卡片、轻阴影、蓝色实底按钮 | 识别鲜明，按钮强调较强 |
| C 暖杏日常 | 暖杏、陶橘、浅橄榄 | 杏色页头块、柔软圆角、温和边线、略偏转图标、浅橘添加按钮 | 亲切温暖，仍保留生活感 |
| D 莓紫软糖 | 莓紫、浅粉、淡蓝 | 轻圆角单行卡片、分组小花标记、轻微偏转圆图标、柔紫按钮 | 更年轻轻松，风格偏柔和 |
| E 青柠俱乐部 | 青柠、墨黑、灰白 | 较重标题、硬边线条、少量偏移阴影、方形图标、青柠按钮 | 活力与个性最强，视觉存在感较高 |
| F 深海夜色 | 深蓝灰、香槟色 | 较轻字重、暗色分层卡片、细线图标、暖色添加按钮 | 安静有质感，需后续验证原生深色系统区与照片内容 |

六版分别管理颜色、几何、深度、标题及图标；同一版的三类“添加”入口使用相同底色、边框、文字色与圆角。无装饰动画；偏转图形不影响实际命中区域。

## 组件与交互合同

- 产品按钮命中区域均至少44×44 CSS px；关键行信息14px、条目名称16px。小屏不缩小时间文本。
- 每行整体可点；加号入口有可访问名称；当前 Tab 通过 `aria-current`、字重与图形同时表示。
- 保留可见键盘焦点样式。点击控件只显示“本页用于风格预览”的短提示，不模拟业务保存成功。
- Tab、详情、添加表单、孩子切换仅为本页视觉入口，未实现对应流程；空、加载、失败、权限、未保存等状态待选定风格后展开。
- 出行继续明确“只显示在日程，不生成待办”；不修改 AI、提醒、家庭或确定性复习规则。
- 无 API、真实身份、儿童图片、持久化、分析上报或外网请求。
