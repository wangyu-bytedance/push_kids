## 设计选择和取舍

采用已有通知组件的底部弹层结构：暖纸底、松绿主按钮、宋体标题、纵向主次操作。比全屏核对页更适合启动时的短表单，也方便逐个孩子处理；比系统confirm多一个原生picker，家长在原处完成纠正。弹层专注一个孩子，不采用多孩子合并表单。

标题“确认本学年年级”，显示本学年、孩子姓名、已记录年级和一个年级选择器。首次启用默认原级，后续默认服务端建议；修改或保持原级都通过“确认年级”提交。“稍后处理”跳过本次当前孩子，继续下一个，不改变全局选中孩子。遮罩/返回可退出当前核对，语义等同稍后；保存期间不退出、不重复提交。后台再进入会重新读取服务端事实。

只有弹窗内一句“确认后，全家共享本学年结果”，档案编辑处不加常驻升级说明、学年切换项或暂停开关。年级选项为小班/中班/大班/一至九年级；档案原有暂不填写/其他/未知值兼容保留。七、八、九年级只是统一显示标签，不据此改历史学习内容。

所有权和调用链不改变Spec02：App前台会话 → children确认候选 → 独立组件 → 服务端原子确认 → 刷新正式年级 → 下一孩子。HTML只模拟交互，不实现服务端规则、权限或真实会话持久化。

## 确切视口、状态与导出

每个状态均导出 **320×568、390×844、430×932**，DPR=1，字体缩放100%，Chrome HTML渲染版本见render-report。19态×3视口=57张PNG；所有导出均为候选设计，不能替代原生节点几何和真机验收。

| State | 场景和可见结果 |
|---|---|
| initial | 存量首次核对二年级，默认仍二年级 |
| annual | 已记录二年级，建议三年级 |
| catchup | 已确认一年级，跨两学年建议三年级；仅一个窗口 |
| corrected | 家长将建议三年级改选四年级 |
| keep | 家长选择仍为二年级，仍可确认 |
| next-child | 当前全局仍小满，独立窗口核对豆豆中班→大班 |
| long-name | 长姓名自然换行；标题、字段、按钮不遮挡 |
| saving | 按钮和picker禁用，显示“正在保存…” |
| error | 页内错误，保留家长所选四年级，可重试或稍后 |
| conflict | 收到已确认/版本冲突，不再提交旧选择；读取最新 |
| latest | 获取成功后展示最新正式三年级，继续队列，无覆盖按钮 |
| profile-edit | 原人工编辑入口；九年级显示，未加常驻规则文案 |
| picker-open | 小班至九年级选项滚轮**示意**；平台原生外观不由本HTML批准 |
| deferred | 当前孩子稍后，队列无剩余时回到原业务页 |
| forbidden | viewer或身份变化后不显示可提交窗口 |
| archived | 归档孩子不弹；归档恢复后的候选使用annual/catchup结构 |
| terminal | 正式九年级不再弹窗 |
| unknown | 未填写/未知值不猜、不弹 |
| confirmed | 当学年已确认不再弹 |

原生picker的打开态受微信与iOS/Android控制，本设计只规定选项、初始值和取消/确认语义，不要求复制HTML滚轮。背景今日页、微信状态栏/胶囊均为合成承载示意，不扩大本次页面改版范围；弹层应能由五Tab相同组件承载。

## 工程与验收约束

- 可操作区最小44×44 logical px，主按钮48px；正文≥14px。按钮纵向排列，picker整行50px。最大内容宽480px；圆角只用现有24/40rpx族。
- 弹层最大高度扣除导航区；正文可滚动，底部按钮固定在弹层内。20px侧距，底部按设备safe-area计算。320短屏和长姓名优先保留操作区，不靠隐藏溢出掩盖布局错误。
- 打开时背景不参与读屏/点击，标题为dialog可访问名称，字段有label，错误留在页内并播报；关闭恢复可访问背景和焦点。原生tabbar按现有弹层协议隔离。HTML的inert/aria仅证明设计语义，原生实现须单独验证。
- 一个前台会话只串行一个窗口，切Tab/页面onShow不重复入队；现有弹层、上传/未保存表单时等待安全点。确认请求失败保留选择；迟到结果与家庭/身份/档案变化须失效，不能覆盖当前孩子。
- 候选最多5，响应≤8KiB；一次会话一次有界读取及必要刷新，不轮询。组件无新框架、外部字体、图片或网络依赖；不在本地持久化儿童信息/共享确认事实，不记录姓名/年级/Token到日志。
- 实施后验证reducer/组件/页面意图、权限/冲突/共享、实际包体/时延、ESLint与小程序校验；原生三视口节点矩形与截图、字体放大、读屏、iOS/Android均待实施后验收。
