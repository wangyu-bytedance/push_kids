## 可见结构

保留“复习条目”原生返回、按时间/科目/次数、明后天/科目/次数筛选、总条目数、分页与条目操作。筛选区按视图使用等宽响应网格：时间两列，科目与次数三列；科目数量增加时自动续行，标签较长时在按钮内换行。此前原型把“指定次数”直接写死为4次是合成演示错误；现在未输入时显示“指定次数”，点击后输入0至2147483647的整数，确认才显示用户所选次数并筛选。原型 `?state=count-custom&n=7` 只演示用户明确输入7后的状态，不是默认值。科目9/50/19项也仅是合成示例。顶部只留一句作用说明；时间视图的日期按钮改写为“预计安排”，结果行明确“明天预计10项·约30分钟”，下行说明预览会随进度更新。空结果仅显示相应空态，不叠加“0项·约0分钟”。

内容区按当前游标页形成科目组卡。卡片采用用户参考图的白纸面、松绿左线、科目字标、组标题、组内分隔线；组头显示“本页 N 项”而非误导为该科目全部知识数。组头是整行点击目标，右侧箭头指示开合；进入一页结果时仅第一科默认展开，其余收起。各科独立开合，可以同时展开多科；收起后仅保留组头，组内按钮不参与点击或键盘导航。切换筛选、分页或孩子上下文后按新结果重置开合。条目名称完整换行，紧凑地列出次数/最近复习、建议或家长安排日期与当前状态；操作是“调整”而非“完成”，不含勾选/原题提示/来源图片，因为本页没有完成反馈或来源数据合同。组顺序按本页首次出现，组内保持API返回顺序；跨页不合并。

“等待安排”是当前状态，明天/后天的列表是预计入选；两者同时出现时，结果区说明它们分别指什么。保留自动日期/手动预约/旧API缺字段的现有状态映射。颜色不是唯一状态信号。条目尾部“…”就近打开非模态下拉菜单，列出“加入明天复习”“改到后天复习”“删除条目”；不再弹出截图中的整屏遮罩/底部调整面板。菜单保留既有禁用条件，删除仍有独立二次确认；点外部、Esc、重复点同一按钮或折叠科目可关闭，靠近视口底部向上弹。一次仅一处菜单展开。

## Required viewport/state matrix

以下状态需要各导出320×568、390×844、430×932，DPR=1。此前24张截图来自旧底部面板原型，不能代表本次“…”菜单修订；重导出前不得用它们批准设计。页面可纵向滚动；导出使用合成示例。原生节点几何与iOS/Android验收在实施后另行记录。

| URL state | Purpose | Critical check |
|---|---|---|
| `time` | 多科、同科多项的明天预计安排 | 第一科展开，其他科收起；“预计”与“等待”语义分开；无完成按钮 |
| `subject` | 单科筛选 | 单组多条、筛选高亮、组数称“本页” |
| `count` | 按次数筛选跨科 | 当前页独立折叠、展开后每条仍显示次数、翻页提示 |
| `count-input` | 点击“指定次数” | 空输入，不预设4次；输入与错误消息对齐 |
| `count-custom?n=7` | 用户显式确认7次的合成示例 | 仅此时按钮显示7次，列表次数随输入值变化 |
| `folded` | 同一结果全部收起 | 每科标题与本页项数仍可扫读、组内操作不可触达 |
| `empty` | 后天无预览 | 单一空态，无重复零统计 |
| `long` | 长中文、长科目名、长状态 | 换行、安全边距、调整目标44px |
| `readonly` | 无编辑权限 | 条目仍可读，调整入口不显示 |
| `actions` | 首项“…”下拉菜单展开 | 就近定位、无整屏遮罩、可用/禁用项可辨认 |

加载、请求错误、冲突、保存中、删除二次确认均沿用既有可见错误恢复与确认语义；实现须回归。原型提供“按时间/科目/次数”、逐科开合与“…”菜单点击演示，仅供审核，不发起请求。

## 工程与验收

生产复用 `styles/tokens.wxss`、既有图标和页面筛选逻辑；不引入运行时依赖或下载完整目录。组头与“…”须提供可访问名称和展开状态，菜单中的禁用按钮不能误触；筛选同行等宽并保持可读换行；正文≥14px、点击目标≥44px，320px仍无水平滚动/遮挡。客户端不计算排期优先级，不改变后端排序或家庭/孩子隔离；分页仅分组当前页。保留404/409/403、只读、迟到响应、旧API缺字段等既有回归。设计PNG不能替代小程序原生三视口几何和真实设备验证。
