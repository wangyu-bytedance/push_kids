- [可编辑离线原型](index.html)可切换六种风格、页面和尺寸。各页主标题靠左，孩子胶囊与标题同一行、靠右对齐。副文案仍独立在标题下方。

- 保留记录类型标题菜单、保存中禁用、遮罩和焦点规则。原有底部选择层、系统 picker、列表内容和权限不变。
