## A. 设置

```text
学习档案                         [旺仔 ▾]
家庭与成员                              ›

每日建议复习时长
用于安排今日复习优先级，超出部分仍会显示
[10 分] [15 分] [20 分] [30 分]

在学科目
数学                              当前状态
语文                              当前状态
英语                              当前状态
家长已添加的其他科目               当前状态
[＋ 添加科目]

课外活动
还没有添加课外活动
[＋ 添加课外活动]
```

初始仅显示三个基础学科选项，启用以服务端配置为准；自定义/其他已添加项正常保留。用户已明确“辅导班=课外活动”，本次统一用“课外活动”，不增加另一套分类。预算说明单独一行，不与四个按钮争抢横向宽度。

添加科目层：标题“添加科目”＋关闭；候选目录可滚动；已添加项有标记；底部“自定义科目”及“添加”可达。输入名称后显示同名校验，保存失败不清输入。取消零写入。

添加课外活动层：直接选择现有目录名称或自定义，不要求先选内容类型。点“添加”后明确显示已添加，再按需设置练习时间。设置和日程展示同一份配置；取消选择不写入，取消后续提醒编辑不撤销已明确添加的活动。

## B. 家庭成员

```text
‹ 家庭与成员

旺仔的家
[邀请家人]
加入申请                         2 条待处理 ›

妈妈                         管理员 · 我  ›
爸爸                         可共同记录   ›
奶奶                         仅查看       ›
```

数量来自服务端；无申请时写“暂无待处理申请”，不能展示演示数字。上面2仅为线框示意。

**本人详情**：显示关系、当前角色和“我”；关系称谓使用现有授权编辑。没有移除本人、退出、本人权限降级按钮。

**其他成员详情（管理员）**：关系称谓可编辑；协作权限显示当前值，点入单选层；“保存修改”一次提交。权限变化确认框明确新权限。底部单独放“移除成员”，确认框写清当前访问失效、历史记录保留；取消不写入。

**非管理员**：详情只读，隐藏管理操作。权限丢失、最后管理员、并发变更显示可见原因并重新读取，不只闪Toast。

邀请：点击“邀请家人”后显示“正在准备邀请”→准备好后“微信邀请家人”；失败时原地重试。只在用户点击分享后调用微信分享，不自动发送，不把原始口令作为主页主要内容。

## C. 今日首次/当日空态

```text

也可以先添加日程。
[记录学习]       [添加日程]

今日复习                          0 项  ∧
            今天没有到期的复习

今日学习                          0 条  ∧
            今天还没有学习记录

今日活动                          0 项  ∧
            今天没有日程安排
```

只有收到成功的当日空结果且没有待处理草稿时才显示这段整体引导。已有部分内容时移除整体引导，保留单栏居中空态和对应小入口。首页不是设置向导，不强制逐步配置所有科目。

“记录学习”进入记录Tab；“添加日程”进入日程并打开新增。取消新增后，普通Tab切换不再次强弹。

加载是骨架；失败是原因＋重试；待确认是明确进入已有草稿的提示。三种状态不能伪装成空态。

## D. 拍照与通用几何

```text
┌────────────────┬────────────────┐
│    拍照记录    │    文字记录    │ ← 文字中心与按钮中心重合
└────────────────┴────────────────┘

┌────────────────┐ ┌────────────────┐
│                │ │                │
│       +        │ │     相册图标   │
│    拍摄一张    │ │    从相册选择  │ ← 图标与文案整组居中
│                │ │                │
└────────────────┘ └────────────────┘
```

两入口宽高一致。正常中文可单行，放大或长文案按内容增高。圆形关闭/加号/刷新保持等宽高；不依赖特殊字符基线生成圆形外框。日期七项等分，320小屏必要时整条使用满视口，七个触控区仍≥44px，不把七天设计成需要横向寻找的列表。
